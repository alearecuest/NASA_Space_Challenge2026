# Farm Clim Tech Mobile Mockups

## Overview
This folder contains mockup designs for the Farm Clim Tech mobile application.

## Files
- **MOCKUPS.html** (in repo root) — Interactive HTML prototype showing all 6 screens side-by-side

## How to View

### Interactive Prototype
1. Open `MOCKUPS.html` in a web browser
2. All 6 device mockups are displayed side-by-side
3. Each mockup shows the exact design system colors, typography, and layout
4. Hover over elements to see interaction states

## Screens Included

1. **Onboarding** — Hero illustration + tagline + CTA
2. **Field Dashboard** — 3 semaphores (Soil, Rainfall, NDVI) + status overview
3. **Risk Calendar** — 12 months + risk assessment detail
4. **Compare Rotations** — 4 ranked rotations, recommended highlighted
5. **Rotation Detail** — 3 reasons + field checklist
6. **Alerts** — Critical, warning, and info alerts
